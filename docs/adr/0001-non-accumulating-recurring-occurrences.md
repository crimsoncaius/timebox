# Default recurring occurrences to non-accumulating

Recurring Task Series default to one current visual responsibility: an incomplete Task Occurrence becomes a historical Skipped Task Occurrence after its recurrence period unless it has a future Planned Block or its scheduled series explicitly keeps unfinished occurrences overdue. Independent Task Occurrences and their Subtasks, Planned Blocks, and Actual Blocks remain durable; All Tasks surfaces one oldest actionable occurrence per series, quotas never carry shortfalls forward, and future occurrences are exposed only in date-specific planning. This intentionally supersedes GitHub issue #28's accumulation rule because preserving every overdue row made routine recurrence overwhelm the working list, while durable hidden occurrences preserve future accountability without that cost.
