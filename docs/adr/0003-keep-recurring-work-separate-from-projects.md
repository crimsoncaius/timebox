# Keep recurring work separate from Projects

Projects are finite groups of Battle Plan Tasks that advance a specific outcome. Recurring Task Series represent ongoing routines, so neither a series nor its Task Occurrences, Quota Trackers, or Session Tasks may belong to a Project. This deliberately excludes project-scoped cadence and conversion of an occurrence into Project work for now: it preserves distinct lifecycle and deletion rules for routines, while avoiding an artificial ownership relationship. Project-scoped cadence is deferred to GitHub issue #94.
