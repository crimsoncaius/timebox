# Broad web card status-flow alignment

On 2026-09-07, the maintainer closed the broad request to align the web card status flow with the mobile experience because it was too general and contained no specific actionable changes.

The request does not identify a concrete interaction problem, a bounded behavior change, or acceptance criteria. It should not be treated as an implementation assignment in this form. A future request describing a specific card interaction and its desired behavior can be evaluated independently; this decision does not reject improvements to web cards in general.
