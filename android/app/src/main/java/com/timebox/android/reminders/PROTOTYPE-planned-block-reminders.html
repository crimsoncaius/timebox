Planned Block Reminders: when does the phone nudge you?

Question: do the agreed scheduling rules for Planned Block Reminders give the right result in awkward cases? The rules: one global lead time; the phone only knows the Planned Blocks it has synced (on app open, when planning on the phone, and a background check every 15 min); a block the phone learns about after its reminder time fires immediately if it hasn't started, and is skipped if it has; each block is reminded at most once, keyed by block + start time, so moving a block re-arms it; a reminder is skipped only if you're already tracking that block; a delivered reminder is silently removed once you switch to that block (anywhere), when the block ends, or when a sync finds it moved or deleted; without exact alarms, Android may deliver a few minutes late (simulated here as 6 min). Move the clock forward, plan blocks on the web or the phone, and watch what fires.
